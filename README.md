# Pebble-watchface-BIG-tabled-forecast
Pebble time 2 watchface with BIG digital time and a tabled weather forecast

## Project Information
- Created from CloudPebble and intended to be connected to CloudPebble
- Designed solely for the new Pebble Time 2
- Watchface code is written in C
- Phone settings are written in JavaScript (PebbleKit JS)
